Chronological Learning Curriculum

4-Phase Professional Roadmap

Structured learning pathway from initial concepts to production engineering mastery.

1

Phase 1: Data Wrangling & SQL

Months 1-2
Key Topics & Skills:
Advanced SQL (Window functions, CTEs) Python (Pandas, NumPy) Data Cleaning Matplotlib / Seaborn
Hands-on Milestone Project: Clean and explore an e-commerce transactional dataset with 1M+ rows.
2

Phase 2: Statistical Rigor & A/B Testing

Months 3-4
Key Topics & Skills:
Hypothesis Testing Confidence Intervals A/B Test Design Regression Analysis
Hands-on Milestone Project: Design, simulate, and analyze an end-to-end A/B test with statistical significance testing.
3

Phase 3: Machine Learning & Modeling

Months 5-6
Key Topics & Skills:
Supervised & Unsupervised Learning Tree-based Models (XGBoost) Clustering Feature Importance
Hands-on Milestone Project: Build a customer lifetime value (LTV) predictive model with hyperparameter tuning.
4

Phase 4: Production Insights & BI

Months 7-8
Key Topics & Skills:
Interactive Dashboards (Streamlit/Tableau) Snowflake/BigQuery Model Explainability (SHAP)
Hands-on Milestone Project: Deploy an interactive executive intelligence portal with dynamic scenario forecasting.
