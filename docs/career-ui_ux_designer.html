UI/UX & Product Designer

UI/UX Designers define how digital software looks, feels, and operates. They run user interviews, craft wireframes and design systems in Figma, and partner with developers to build accessible, high-converting interfaces.

Chronological Learning Curriculum

4-Phase Professional Roadmap

Structured learning pathway from initial concepts to production engineering mastery.

1

Phase 1: Design Fundamentals & Figma

Months 1-2
Key Topics & Skills:
Figma Auto-layout & Components Color Theory & Typography Visual Hierarchy Heuristic Evaluation
Hands-on Milestone Project: Redesign a complex checkout flow in Figma with responsive component variants.
2

Phase 2: User Research & Wireframing

Months 3-4
Key Topics & Skills:
User Personas Journey Mapping Low-fi Wireframes Information Architecture
Hands-on Milestone Project: Conduct 5 user interviews and map out a comprehensive user onboarding journey.
3

Phase 3: Design Systems & Advanced Prototyping

Months 5-6
Key Topics & Skills:
Token-based Design Systems Interactive Figma Prototyping Micro-interactions WCAG 2.1 AA
Hands-on Milestone Project: Build an enterprise multi-brand design system with documentation.
4

Phase 4: Portfolio & Dev Handoff

Months 7-8
Key Topics & Skills:
Design Tokens Handoff Case Study Writing Portfolio Review Live Usability Testing
Hands-on Milestone Project: Publish a 3-case-study product design portfolio ready for senior interviews.
