Engineering Principles

How CareerNova AI Operates

A transparent, deterministic career recommendation engine paired with an optional generative AI executive layer.

1. Deterministic Multi-Factor Alignment

Unlike generic chatbots that often hallucinate career advice or generate superficial suggestions, CareerNova uses a mathematically grounded multi-factor evaluation algorithm:

  • Core Skill Overlap (Weight: 3.0x): We compute direct matches against verified industry requirements for each role.
  • Secondary Toolchains (Weight: 1.5x): Supporting competencies like Git, Docker, cloud platforms, and testing.
  • Domain Passion Alignment: Interest vectors that correlate with daily problem types.
  • Work Environment Preference: Remote, high-availability, research-heavy, or fast-paced startup squads.

✦ Explainability Guarantee: Every recommendation clearly separates the skills you already possess from the high-leverage skills you must prioritize.

2. Dual Intelligence Architecture

CareerNova was engineered from day one to operate with 100% functionality without requiring external paid API keys.

Core Engine (Always Active)

Generates instant match percentages, radar dimensions, 4-stage curriculums, and heuristic action plans with 0ms external API delay.

AI Executive Layer (Optional)

When an AI_API_KEY is present in environment variables, the platform calls Google Gemini 1.5 Flash to synthesize dynamic customized interview strategies.

3. Production & Vercel Native Architecture

The application runs as a modern Flask WSGI serverless function natively compatible with Vercel's Python 3.12 runtime:

  • Serverless PostgreSQL Pooling: Built for managed providers like Neon and Supabase, with automatic pool_pre_ping and SSL enforcement.
  • Strict Security Standards: Scrypt password hashing via Werkzeug, CSRF token validation on all state mutations, and HTTPS-enforced session cookies.
  • Zero Local File Dependencies: No brittle persistent local disk storage or heavy unoptimized packages.
